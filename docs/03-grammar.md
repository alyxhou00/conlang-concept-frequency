# 03. Grammar

Principle: **sentences as short as possible.** Nothing has to be marked; particles are added only when needed. The language is analytic (isolating): words never change form.

Examples use concept names (GLOSSES) and the current words.

## Overview / 總覽

| Topic | Decision | Example |
| --- | --- | --- |
| Word order | SVO | I SEE DOG — *ö rö tön* |
| Modifiers | After the noun (adjectives, possessors, relative clauses, numerals) | DOG BIG — *tön la* |
| Particles | After the word they modify | GO NOT — *eh ë* |
| Adpositions | Postpositions | DIGNITY IN — *etrit po* |
| Obligatory marking | None (number, tense, voice, case all optional) | PERSON = one person or many |
| Yes/no questions | Question particle at the start | Q THOU GO — *ih a eh* |
| Question words | Stay in place | THOU SEE WHO — *a rö an* |
| Copula | Adjectives are predicates directly; BE only before a noun | PERSON FREE — *ken mat*; HE BE TEACHER — *e ru ison* |
| Possession | Juxtaposed, possessor after | DOG I — *tön ö* "my dog" |
| Numerals | After the noun, no classifiers | PERSON THREE — *ken koh* |
| Compounds | Existing words, head first | TREE COCONUT — *isu öhkoh* |

## Particles / 小詞

| Particle | Word | Use |
| --- | --- | --- |
| NOT | *ë* | after the verb: GO NOT |
| PAST | *mö* | after the verb, only when needed: GO PAST |
| PLURAL | *ral* | after the noun, only when needed: PERSON PL |
| QUESTION | *ih* | at the start of a yes/no question |
| SHOULD | *vih* | after the verb: DO SHOULD |

## Pronouns / 代名詞

Singular vs. plural, and inclusive vs. exclusive "we". No gender, no politeness levels, no case: the same word is subject, object and possessor.

| | Singular | Plural |
| --- | --- | --- |
| 1st | I — *ö* | WE (EXCLUSIVE) — *ne*; WE (INCLUSIVE) — *pë* |
| 2nd | THOU — *a* | YOU — *së* |
| 3rd | HE OR SHE OR IT — *e* | THEY — *lo* |

## Not decided yet / 尚未決定

- Tense and aspect beyond PAST (future, perfective …).
- Relative clauses: a marker or plain juxtaposition.
- Comparison ("bigger than").
- Numbers above ten.
- Root families (deriving related words from a shared root).
